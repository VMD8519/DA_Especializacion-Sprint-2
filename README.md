# Sprint de Análisis de Base de Datos Relacional 📊

¡Bienvenidos! 😄 En este sprint, tuve la oportunidad de trabajar con una base de datos relacional que contiene información detallada sobre una empresa dedicada a la venta de productos online. Este sprint fue clave para explorar y aprender más sobre cómo interactuar con bases de datos relacionales en el ámbito de ventas online. 
¡Vamos a ver de qué se trató! 🚀

## Objetivos del Sprint 🎯
Durante este sprint, los objetivos principales fueron:
- Comprender la estructura de la base de datos 📚
- Realizar consultas básicas en SQL 📝
- Trabajar con relaciones entre tablas 🔗
- Ejecutar análisis de transacciones realizadas 💳

## Actividades Realizadas 🛠️
1. Exploración de la Estructura de la Base de Datos 🔍
2. Consultas Básicas en SQL 🖥️
3. Trabajo con Relaciones entre Tablas 🔗
4. Análisis de Transacciones 💡

## Resultados y Aprendizajes 📈
Este sprint ha sido una excelente oportunidad para repasar y fortalecer mis habilidades en bases de datos relacionales. Al final del sprint, me siento mucho más confiado al trabajar con bases de datos y ejecutar consultas SQL básicas. He mejorado mi capacidad para analizar datos relacionados con ventas online y, sobre todo, he aprendido a interactuar con bases de datos de manera más eficiente. 🎉
